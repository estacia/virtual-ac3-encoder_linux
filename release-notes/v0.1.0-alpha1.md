# v0.1.0-alpha1 — Standalone CachyOS x86_64 Release

This is the first prebuilt Linux release of the native PipeWire AC-3 encoder.

## Features
- PipeWire virtual 5.1 F32P sink
- FFmpeg AC-3 encoding up to 640 kbit/s
- IEC 61937 AC-3 carrier output
- Dynamic time-domain 5.1 matrix, Dual Stereo Copy, and untouched modes
- EXTREME preset with 128 safe frames
- System-wide PipeWire configuration included

## Installation
```bash
sudo pacman -S --needed pipewire ffmpeg
sudo tar -C / -xzf virtual-ac3-encoder-cachyos-x86_64.tar.gz
systemctl --user restart pipewire pipewire-pulse wireplumber
```

The release asset is an x86_64 PipeWire module bundle, not a statically linked standalone application. It uses the host's PipeWire and FFmpeg shared libraries. Compatible runtime ABI versions are required.

## Validation
The release workflow compiles the module and runs the core test suite on Arch Linux. Actual HDMI / S/PDIF / eARC playback and end-to-end latency have not yet been tested on physical hardware. Experimental alpha software.
