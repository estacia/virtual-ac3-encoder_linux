# v0.1.0-alpha2 — Portable CachyOS x86_64 bundle

This release bundles a private FFmpeg 9.1 runtime containing only the shared libraries needed for AC-3 encoding (libavcodec and libavutil). The bundled FFmpeg build enables the AC-3 and AC-3 fixed-point encoders, and disables GPL components and x86 assembly.

The system FFmpeg package is no longer required by the prebuilt bundle.

## PipeWire runtime requirement

This software remains a PipeWire module. It is loaded into the already-running system PipeWire daemon and links to the host's libpipewire-0.3 ABI. PipeWire is deliberately not copied into the module bundle: a private PipeWire library loaded into the host daemon would be ABI-unsafe, and a private daemon would create a separate audio graph rather than a virtual sink in the user's current graph.

The host must provide PipeWire, glibc, libstdc++, and standard system libraries.

## Install

```bash
sudo pacman -S --needed pipewire
sudo tar -C / -xzf virtual-ac3-encoder-cachyos-x86_64-ffmpeg-bundled.tar.gz
systemctl --user restart pipewire pipewire-pulse wireplumber
```

## Assets

- virtual-ac3-encoder-cachyos-x86_64-ffmpeg-bundled.tar.gz: installed PipeWire module, bundled FFmpeg libraries, configuration and notices
- matching .sha256 checksum
- ffmpeg-9.1.tar.xz and matching checksum: corresponding LGPL source archive for the bundled FFmpeg libraries

The release is built and tested against Arch Linux packages. The AC-3 encoder smoke test verifies actual encoding of one 5.1 frame. Physical HDMI / S/PDIF / eARC playback and end-to-end latency have not yet been validated on target hardware. Experimental alpha.
